# 오늘은 야끼소바

한국어 야끼소바 레시피 홈페이지. 모바일 레이아웃, 1–8인분 재료 조절, 재료 체크, 레시피 인쇄를 지원합니다. HTML, CSS, JavaScript만 사용하며 빌드와 외부 의존성이 없습니다.

## 로컬 실행

`python3 -m http.server 8000` 실행 후 http://localhost:8000 에 접속합니다.

## 배포

GitHub 저장소의 Settings → Pages → Source를 GitHub Actions로 설정합니다. main 브랜치에 push하면 `.github/workflows/pages.yml`이 사이트를 배포합니다.
